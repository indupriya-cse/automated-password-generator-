# Automated Password Generator & Strength Evaluation System

A Python-based project that generates secure random passwords and evaluates their strength based on length, uppercase letters, lowercase letters, numbers, and special characters.

## Features

- Generates random secure passwords
- Evaluates password strength
- Checks password length
- Checks uppercase and lowercase characters
- Checks numbers and special characters
- Simple and easy to use

## Technologies Used

- Python
- Random module
- String module

## How It Works

1. The program generates a random password.
2. It checks different password security conditions.
3. A strength score is calculated.
4. The password is classified as Weak, Medium, or Strong.

## Project Purpose

The project demonstrates basic Python programming, functions, conditional statements, string handling, and password security concepts.
